# Information Kiosk for School Campus using PyQt5

## Internship Project with Unique World Robotics

### Project Overview
This project is an Information Kiosk for a school campus, developed using PyQt5. It was created as part of an internship with Unique World Robotics. The kiosk provides an interactive interface for students and visitors to access information about the campus.

### Installation Instructions
To set up the project locally, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/jj7258/expert-guide.git
   cd expert-guide
   ```

2. Create a virtual environment:
   ```sh
   python -m venv env
   source env/bin/activate  # On Windows use `env\Scripts\activate`
   ```

3. Install the required dependencies:
   ```sh
   pip install pyqt5 google-api-python-client openweather-api
   ```

4. Run the application:
   ```sh
   python School_Reception.py
   ```

### Usage
To use the application, simply run the `School_Reception.py` script after installing the dependencies. The kiosk interface will open, allowing users to navigate and find information about the school campus.

### Features
- **Interactive Interface:** User-friendly interface for easy navigation.
- **Dynamic Content:** Displays up-to-date information about the campus.
- **Search Functionality:** Allows users to search for specific information.
